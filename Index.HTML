SEJARAH SINGKAT

Fungsi tidak ditemukan oleh satu orang saja

Gagasan tentang hubungan antara dua besaran tumbuh perlahan dalam sejarah matematika. Tabel bilangan bangsa Babilonia kuno dapat dipahami sebagai contoh hubungan input-output, meskipun mereka belum memakai pengertian fungsi modern.

1673Gottfried Wilhelm Leibniz

Menggunakan kata “fungsi” saat membahas garis-garis pada geometri.

1718Johann Bernoulli

Menerbitkan rumusan awal yang terkenal: fungsi sebagai besaran yang dibentuk dari variabel dan konstanta.

1748–1755Leonhard Euler

Menjadikan fungsi pusat analisis: mula-mula sebagai ekspresi analitik, lalu juga sebagai besaran yang bergantung pada besaran lain.

Lihat perkembangan konsep fungsi dari masa ke masa
  1. Sebelum istilah fungsi: juru tulis Babilonia membuat tabel kuadrat dan kebalikan. Ptolemaios (abad ke-2 M) menyusun tabel tali busur lingkaran, sedangkan Āryabhaṭa (499 M) menyajikan tabel sinus. Ini adalah hubungan nilai yang dapat dibaca sebagai input-output, tetapi belum merupakan definisi fungsi modern.
  2. Abad ke-14: Nicole Oresme menggambarkan perubahan besaran, seperti kecepatan, secara visual dengan garis. Ia pelopor penting grafik perubahan, bukan pencipta tunggal konsep fungsi.
  3. Abad ke-17: Fermat dan Descartes menghubungkan aljabar dengan geometri; karya Descartes terbit pada 1637. Leibniz memakai istilah function dalam manuskrip 1673 untuk besaran geometris pada kurva, bukan pemetaan antarihimpunan seperti definisi sekolah sekarang.
  4. 1718 dan 1748–1755: Bernoulli merumuskan fungsi sebagai besaran yang dibentuk dari variabel dan konstanta. Euler memperluas pemakaiannya dalam analisis dan membahas ketergantungan antarbesaran.
  5. Abad ke-19: Fourier, Dirichlet (1829 dan 1837), serta Lobachevsky membantu menunjukkan bahwa fungsi tidak harus selalu satu rumus aljabar sederhana; suatu kondisi atau aturan lain juga dapat menentukan output.
  6. 1888 hingga abad ke-20: Dedekind mengembangkan gagasan pemetaan unsur suatu sistem ke unsur lain. Tradisi teori himpunan, termasuk karya Bourbaki, membantu menata pengertian fungsi modern secara formal.

Tanggal dan peran di atas merujuk pada tahap tertentu dalam perkembangan gagasan. Tidak satu pun tokoh tersebut menciptakan seluruh pengertian fungsi modern sendirian.

Jadi, fungsi matematika modern berkembang melalui banyak pemikiran, bukan “ditemukan” sekaligus. Sumber sejarah konsep fungsi

UNIT 01 / RELASI DAN FUNGSI

Apa itu fungsi, dan bagaimana cara mengenalinya?

Definisi dan notasi

Fungsi adalah aturan yang memasangkan setiap anggota domain (input) dengan tepat satu anggota kodomain (output). Ditulis f: A → B: f adalah nama aturan, A adalah domain, dan B adalah kodomain. Jika inputnya x, outputnya ditulis f(x), dibaca “f dari x”.

Fungsi boleh memberi output sama untuk input berbeda. Yang dilarang adalah satu input memiliki dua output berbeda. Pikirkan mesin: masukkan x, jalankan aturan yang tetap, lalu baca satu hasil f(x).

Contoh fungsi: A = {1, 2}, aturan f(x) = x + 3 memberi 1 → 4 dan 2 → 5.
Bukan fungsi: relasi memasangkan 1 → 4 sekaligus 1 → 7.

Cara memeriksa

  1. Catat semua anggota domain/input.
  2. Pastikan setiap input mendapat pasangan.
  3. Pastikan satu input tidak punya lebih dari satu output.

Asal-usul dan tokoh

Konsep fungsi berkembang bertahap, jadi tidak tepat menyebut satu “penemu fungsi”. Tabel hitung Babilonia kuno dapat dilihat sekarang sebagai contoh hubungan input-output, tetapi belum memakai definisi fungsi modern. Leibniz memakai kata “fungsi” pada 1673 saat membahas garis; Johann Bernoulli membahasnya sebagai istilah matematika pada 1694. Euler membuat gagasan fungsi penting dalam analisis pada 1748 dan memberi definisi lebih umum pada 1755.

Tokoh-tokoh ini berperan pada tahap berbeda; mereka bukan sendirian menciptakan seluruh konsep modern.

Coba sendiri: apakah 1 → a, 2 → a termasuk fungsi?

Ya. Kedua input masing-masing memiliki tepat satu output. Outputnya kebetulan sama, dan itu diperbolehkan.

Fungsi bukan cuma rumus: tabel, diagram, grafik, dan aturan

Lima cara menyatakan fungsi

  1. Rumus: f(x) = 2x + 3.
  2. Tabel: daftar input x dan output f(x).
  3. Diagram panah: garis dari setiap input ke tepat satu output.
  4. Grafik: titik-titik (x, f(x)) pada bidang koordinat.
  5. Aturan verbal: misalnya setiap orang dipasangkan dengan tanggal lahirnya.

Uji garis vertikal

Pada grafik hubungan y terhadap x, setiap garis vertikal hanya boleh memotong grafik paling banyak sekali. Jika satu garis x tertentu memotong dua titik, satu input x memiliki dua output y, jadi hubungan itu bukan fungsi y terhadap x.

y² = x memberi y = 2 dan y = −2 saat x = 4, jadi bukan satu fungsi y(x). Jika dipilih satu cabang, misalnya y = √x dengan x ≥ 0, barulah setiap x memiliki satu output.

Secara formal, grafik fungsi f: A → B adalah himpunan pasangan {(x, f(x)) | x ∈ A} yang menjadi bagian dari A × B. Rumus hanyalah salah satu cara menuliskan aturan pemetaannya.

UNIT 02 / DOMAIN, KODOMAIN, DAN RANGE

Input mana yang boleh, dan output mana yang muncul?

Tiga istilah yang jangan tertukar

DomainSemua input yang disediakan atau diperbolehkan.
KodomainHimpunan tujuan tempat output diharapkan berada.
RangeOutput yang benar-benar dihasilkan dari domain.
f(x) = 2x, domain {1, 2, 3}, kodomain {2, 4, 6, 8}. Hitung: f(1) = 2, f(2) = 4, f(3) = 6. Maka range = {2, 4, 6}. Angka 8 ada di kodomain, tetapi tidak di range.

Domain jika rumusnya diberikan

  • Penyebut tidak boleh nol: 1/(x − 2) mensyaratkan x ≠ 2.
  • Isi akar berpangkat genap harus ≥ 0: √(x − 1) mensyaratkan x ≥ 1.
  • Isi logaritma harus > 0: log(x − 2) mensyaratkan x > 2.
  • Untuk f(x) = x² dengan domain semua bilangan real, nilai terkecil output adalah 0, jadi range-nya y ≥ 0.
Jenis fungsi umum dan domainnya
  • Konstan: f(x) = c; output selalu c.
  • Identitas: f(x) = x; setiap input menjadi outputnya sendiri.
  • Linear (istilah sekolah): f(x) = ax + b; grafiknya garis lurus.
  • Kuadrat: f(x) = ax² + bx + c; grafik umumnya parabola.
  • Rasional: perbandingan polinomial, misalnya 1/(x − 2); penyebut tidak boleh nol.
  • Akar, eksponensial, logaritma, trigonometri, dan fungsi potongan: masing-masing memiliki aturan dan batas domain yang perlu diperiksa.

Daftar ini adalah contoh jenis yang umum dipelajari, bukan daftar lengkap semua fungsi dalam matematika.

Asal-usul istilah

Domain, kodomain, dan range adalah istilah untuk menjelaskan bagian-bagian pemetaan. Tidak ada satu penemu tunggal yang secara aman dapat diklaim untuk ketiga istilah ini dalam pelajaran sekolah; penggunaannya berkembang bersama bahasa modern tentang fungsi dan himpunan.

Range bergantung pada aturan dan domain yang dipilih. Mengubah domain dapat mengubah range, walaupun rumusnya tetap.

Coba sendiri: domain 1/(x − 2) boleh memuat x = 2?

Tidak. Jika x = 2, penyebut menjadi nol sehingga pembagian tidak terdefinisi. Domain realnya adalah semua bilangan real kecuali 2.

UNIT 03 / KOMPOSISI FUNGSI

Menyambungkan dua aturan: kerjakan fungsi bagian dalam dahulu

Makna dan urutan

Komposisi membuat output suatu fungsi menjadi input fungsi lain. (f ∘ g)(x) = f(g(x)) artinya mulai dari x, jalankan g, lalu masukkan hasilnya ke f. Simbol dibaca “f komposisi g”, tetapi g dikerjakan lebih dahulu karena berada di bagian dalam.

Diketahui f(x) = 2x + 1 dan g(x) = x².
Hitung (f ∘ g)(2):
1. g(2) = 2² = 4.
2. f(4) = 2(4) + 1 = 9.
Jadi (f ∘ g)(2) = 9.
Urutan dibalik: (g ∘ f)(2) = g(f(2)) = g(5) = 5² = 25. Maka f ∘ g umumnya tidak sama dengan g ∘ f.
Operasi fungsi lain dan fungsi dengan beberapa input

Jika f(x) = 2x + 1 dan g(x) = x − 3, operasi dilakukan pada output untuk input yang sama:

  • (f + g)(x) = (2x + 1) + (x − 3) = 3x − 2.
  • (f − g)(x) = (2x + 1) − (x − 3) = x + 4.
  • (fg)(x) = (2x + 1)(x − 3).
  • (f/g)(x) = (2x + 1)/(x − 3), dengan syarat x ≠ 3 karena pembagi tidak boleh nol.

Fungsi tidak harus satu input

Luas lingkaran bergantung pada jari-jari: A(r) = πr². Volume tabung bergantung pada dua input, jari-jari dan tinggi: V(r,h) = πr²h. Setiap pasangan input yang diizinkan tetap harus menghasilkan tepat satu output.

Asal-usul dan syarat

Menyusun aturan secara berurutan adalah ide yang muncul dari pemakaian fungsi; tidak ada satu tokoh yang secara umum diakui sebagai penemu tunggal operasi komposisi fungsi. Notasi f ∘ g adalah cara ringkas untuk menulis urutan itu.

Komposisi terdefinisi hanya jika output g(x) bisa menjadi input f—dengan kata lain, hasil g berada dalam domain f.

Coba sendiri: jika f(x) = x + 4 dan g(x) = 3x, hitung (g ∘ f)(2).

Kerjakan f dahulu: f(2) = 6. Lalu g(6) = 3 × 6 = 18. Jadi (g ∘ f)(2) = 18.

UNIT 04 / FUNGSI INVERS

Membalik aturan dengan mengembalikan output menjadi input

Definisi, langkah, dan pemeriksaan

Fungsi invers f⁻¹ membalik pemetaan: jika f mengubah x menjadi y, f⁻¹ mengubah y kembali menjadi x. Notasi f⁻¹ bukan berarti 1/f(x). Agar invers juga merupakan fungsi, fungsi asal harus satu-ke-satu pada domain yang dipakai—setiap output berasal dari satu input.

Contoh f(x) = 2x + 4:
1. Tulis y = 2x + 4.
2. Tukar x dan y: x = 2y + 4.
3. Selesaikan untuk y: y = (x − 4) / 2.
Jadi f⁻¹(x) = (x − 4) / 2.

Cek: f⁻¹(f(x)) = ((2x + 4) − 4)/2 = x. Domain invers berasal dari range fungsi asal, dan range invers berasal dari domain fungsi asal.

Injektif, surjektif, dan bijektif: kapan invers tersedia?
  • Injektif: input berbeda tidak menghasilkan output yang sama. Ini syarat agar invers menjadi fungsi pada range asal.
  • Surjektif: setiap anggota kodomain benar-benar menjadi output. Sifat ini bergantung pada kodomain yang dipilih.
  • Bijektif: sekaligus injektif dan surjektif. Fungsi bijektif memiliki pasangan satu-satu antara seluruh domain dan kodomain.
f: ℝ → ℝ, f(x) = 2x + 1 bersifat bijektif. Untuk setiap y ada tepat satu x = (y − 1)/2, sehingga f⁻¹(y) = (y − 1)/2. Sebaliknya, f(x) = x² pada ℝ tidak injektif karena f(2) = f(−2) = 4.

Asal-usul dan kapan invers ada

Gagasan membalik pemetaan berkembang bersama teori fungsi dan relasi; tidak ada satu orang yang dapat disebut penemu tunggal fungsi invers. Syarat satu-ke-satu bukan formalitas: f(x) = x² pada domain semua real tidak punya invers berupa fungsi, sebab 4 berasal dari x = 2 maupun x = −2.

Jika domain dibatasi x ≥ 0, x² menjadi satu-ke-satu dan inversnya √x. Secara grafik, fungsi satu-ke-satu lolos uji garis horizontal.

Coba sendiri: apa invers f(x) = 3x − 6?

Tukar x dan y: x = 3y − 6. Maka 3y = x + 6, sehingga f⁻¹(x) = (x + 6)/3.

05 / MENGENAL FUNGSI LINEAR

Apa itu fungsi linear?

Di pelajaran sekolah, fungsi linear biasanya ditulis f(x) = ax + b (atau y = mx + c) dan grafiknya berupa garis lurus. Setiap x naik satu satuan, output berubah sebesar a. Jika a positif garis naik, jika negatif garis turun, dan jika a = 0 garis mendatar.

aGradien/kemiringan garis. Jika a > 0 garis naik; jika a < 0 garis turun; jika a = 0 garis mendatar.
bTitik potong sumbu-y, yaitu nilai fungsi ketika x = 0.
Menentukan rumus dari dua titik: f(0) = 3 dan f(2) = 7.
a = (7 − 3)/(2 − 0) = 2, lalu b = f(0) = 3.
Jadi f(x) = 2x + 3. Cek: f(2) = 2(2) + 3 = 7.
Rumus gradien dan cara membentuk fungsi dari dua titik

Jika garis melalui (x₁, y₁) dan (x₂, y₂), dengan x₁ ≠ x₂, maka:

a = (y₂ − y₁)/(x₂ − x₁)
b = y₁ − ax₁
f(x) = ax + b

Contoh titik (2, 7) dan (5, 16): a = (16 − 7)/(5 − 2) = 3, lalu b = 7 − 3(2) = 1. Jadi f(x) = 3x + 1. Bentuk ax melalui titik asal; bentuk ax + b dengan b ≠ 0 memotong sumbu-y di b.

Asal-usul dan catatan istilah

Hubungan linear dan persamaan garis berkembang sepanjang sejarah aljabar dan geometri; tidak ada satu penemu tunggal yang dapat diklaim untuk seluruh konsep fungsi linear. Rumus dan grafik yang dipakai di sekolah adalah cara modern untuk menyatakan hubungan dengan perubahan tetap.

Catatan transparan: di sekolah, ax + b sering disebut fungsi linear. Dalam aljabar linear tingkat lanjut, “pemetaan linear” biasanya mensyaratkan f(x) = ax (b = 0); bentuk ax + b dengan b ≠ 0 secara lebih khusus disebut afin. Ikuti istilah yang digunakan di kelasmu.

Coba sendiri: jika f(x) = 2x + 3, berapa perubahan output ketika x naik dari 4 ke 5?

Output naik 2, sama dengan gradien a. f(4) = 11 dan f(5) = 13.
