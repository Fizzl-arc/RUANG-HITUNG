KOMPOSISI & INVERS

01 / Komposisi

Fungsi di dalam fungsi

Komposisi (f ∘ g)(x) = f(g(x)) berarti masukkan hasil fungsi g ke dalam fungsi f. Kerjakan fungsi paling dalam terlebih dahulu: cari g(x), kemudian gunakan hasil itu sebagai masukan f. Nilai keluaran g harus termasuk dalam domain f agar komposisi terdefinisi.

f(x) = 2x + 1,  g(x) = x²

(f ∘ g)(x) = f(x²) = 2x² + 1

Untuk x = 2: g(2) = 4, lalu f(4) = 9. Sebaliknya, (g ∘ f)(2) = g(5) = 25. Jadi, urutan komposisi umumnya tidak dapat ditukar.

Ingat: f ∘ g dibaca “f komposisi g”, tetapi yang dikerjakan lebih dahulu adalah g.

02 / Fungsi invers

Balikkan pemetaannya

Fungsi invers membalik proses fungsi asal: jika f memetakan masukan menjadi keluaran, maka f⁻¹ memetakan keluaran itu kembali ke masukan. Invers bukan berarti 1/f(x). Agar inversnya menjadi fungsi, setiap keluaran fungsi asal harus berasal dari tepat satu masukan (fungsi satu-ke-satu).

f(x) = ax + b,  a ≠ 0

f⁻¹(x) = (x − b) / a

Langkah: tulis y = ax + b → tukar x dan y menjadi x = ay + b → isolasi y, sehingga y = (x − b)/a.

Contoh f(x) = 2x + 4: y = 2x + 4 → tukar x dan y menjadi x = 2y + 4 → y = (x − 4)/2. Jadi, f⁻¹(x) = (x − 4)/2. Pemeriksaan: f⁻¹(f(x)) = ((2x + 4) − 4)/2 = x.

Relasi, fungsi, domain, dan range

Relasi memasangkan anggota suatu himpunan dengan anggota himpunan lain. Relasi disebut fungsi jika setiap anggota domain (daerah asal) dipasangkan dengan tepat satu anggota kodomain (daerah kawan). Anggota kodomain yang benar-benar mendapat pasangan disebut range (daerah hasil).

Domain

Nilai masukan yang diperbolehkan, biasanya ditulis x.

Kodomain

Himpunan tujuan yang ditetapkan untuk keluaran fungsi.

Range

Kumpulan keluaran yang benar-benar dihasilkan dari domain.

Contoh: pada f(x) = 2x + 3, jika domain yang dipakai adalah {0, 1, 2}, maka keluarannya berturut-turut {3, 5, 7}. Setiap x memiliki satu keluaran, sehingga aturan ini memenuhi definisi fungsi. Satu x yang memiliki dua keluaran berbeda bukan fungsi.

Simulator langsung

Evaluasi fungsi linear

Atur a, b, dan nilai x. Hasilnya diperbarui otomatis.

f(x) = ax + b

f(4) = 2 × 4 + 3

Substitusi nilai x ke dalam rumus.

Hasil11

Contoh langkah demi langkah

Untuk f(x) = 2x + 3, jika x = 2, maka f(2) = 2(2) + 3 = 4 + 3 = 7. Pada simulator, dengan x = 4, hasilnya f(4) = 11.

Contoh lain: f(x) = 3x − 2, sehingga f(4) = 3(4) − 2 = 12 − 2 = 10.

Makna a dan b

Pada f(x) = ax + b, a adalah gradien: perubahan keluaran ketika x naik 1 satuan. Jika a positif grafik naik, jika a negatif grafik turun, dan jika a = 0 hasilnya konstan. b adalah nilai fungsi saat x = 0 (titik potong sumbu-y).

Hati-hati dengan tanda negatif dan urutan operasi: hitung perkalian sebelum penjumlahan. Contoh, jika f(x) = −2x + 1, maka f(−3) = (−2)(−3) + 1 = 7.
